# Delivering

Read by the hooks when the run-job skill starts. Each pointer says what to open and why.

- docs/delivery.md: shows what grid deliver refuses (waiting proposals, missing proof, empty plans), so you do not meet the refusal at the end.
- grid brain keep: lists the proposals that block delivery; run it before grid deliver to know whether a curator has work first.
- grid proof index: rebuilds the proof index, so every plan item shows proven or not before you claim the work is done.
