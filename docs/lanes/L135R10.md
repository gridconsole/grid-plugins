## The rule

The floor (literal-word check) is skipped for a command the tokenizer proves read-only, as
before. The L135R9 proof stays as it was (`hostReadsIn` with a strict `hostWhole`). One more
route to the same skip is added: the proof with the three relaxations below, and main's own
`onlyReads(command, flatten(command))` true for both readings of the whole command
(`hostWhole.relaxed`). So everything newly allowed is a line main's textual check also reads
as a read; where main refuses (its flatten splits on `{`, `}`, `<`, `>`, a leading `#` line), the
lane refuses as before (`rg -g '{*.md,*.go}' x lnk`, `rg -n "${PAT}" lnk`, o02, o06, o24).

Relaxations, each only when `relaxed`:

1. A skipped `#` comment no longer ends the proof. flatten sees the comment text as commands, so
   `cat x # a` NL `tee alias` is refused by onlyReads (d01-d04, a02, a04, a09, a12, n33, n36 too).
2. An assignment to an array element by number (`x[0]=`, `x[12]+=`) no longer ends the proof: a
   number names no command, so BASH_CMDS[0]=, functions[0]= shadow nothing. `PATH[..]`, `path[..]`
   (zsh path[1]= is tied to PATH and writes) and `IFS[..]` stay refused, as does any other subscript.
3. A find or rg argument that holds `$`, a backtick or `{` is no longer a runner when it is calm
   (`hostShellToken.calm`): (a) the shell expands nothing in it (`'-x$'`: `$` in '..', `{` in any
   quotes), or (b) it is a lone `"$NAME"` or `"${NAME}"` (`dq`) for a name the whole command only
   reads (`hostPlainVar`): every use of NAME is `$NAME` or `${NAME}`, no `printf` runs (printf -v
   sets by name) and the name is not `_` (the last argument of the previous command). A variable
   the command never sets holds what the shell inherited, which the command does not choose.
   `$x` unquoted, `"$x"y`, `$(..)`, `{a,b}`, `$'..'` and `"-e"$x` stay runners.

The tokenizer now records `live` (a `$`, backtick or `{` the shell expands) and `dq` (the word is one
`".."`); `hostSegments` takes the `hostWhole` so a substitution body is judged against the whole
command, not against itself.
