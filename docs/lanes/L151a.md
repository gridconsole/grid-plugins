## Changed
- internal/workflow/tasksteps.go: `TaskSteps(r where.Resolver, project, taskText string) ([]taskfile.WorkflowStep, error)`.
  - Inline `workflow:` list: `taskfile.WorkflowSteps`; malformed or empty -> "task.md workflow list is malformed". Templates are not read.
  - `workflow: <name>`: the project's template (a copy included) before the workspace's, case-insensitive, through `read(r, project, false)`. Any file-level Problem, or a Problem on a section of that name, is an error; not found -> `no workflow is named "<name>"`.
  - Project `personal` (EqualFold `where.Personal`): the workspace file only, through `readFile` + `Parse`; a caller without Personal access gets `projectSelectionError`, as the project path does.
  - Empty or absent name: the workspace `Default` template, only when no template in scope has `applies when` rules and no section in scope failed to parse (a broken section may hold a rule, so it needs a choice too); else "task.md names no workflow and the rules need a choice".
  - Steps map to `{lower(name), kind}`, filtered by size (small S, normal N, large L). auto/''/absent with any step not "SNL" -> "task size is not set; the workflow's steps depend on it". An unknown size word, a non-string workflow, no project, or unreadable front matter -> error. Step names pass the inline reader's rule; at least one step remains after the filter. Never (empty, nil). Errors carry no OS strings (`fileReason`, `Problem.String`).
- internal/task/task.go `Fold`: decodes the front matter to a `yaml.Node`, drops the `workflow` pair when it is a sequence and the only `workflow` key, then decodes `Record`. `Record.Workflow` stays ""; the `task show`/`task list` JSON is unchanged. Checked against the old decode on 12 inputs (empty, null, scalar, sequence, duplicate keys, aliases, map, numbers): only `workflow: [list]` changed.
- Tests: internal/workflow/tasksteps_test.go (28 rows, each asserts never (nil, nil)), internal/task/fold_inline_test.go (3), internal/workflow/oldtask_test.go new `TestWorkflowOldInlineTaskStillReads` with testdata/legacy-inline-task.md. No existing test changed.
