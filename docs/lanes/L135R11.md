## Decision applied (o04)

`rg -n "$PAT" workflows.md` is no longer a required read. A quoted `"$NAME"` argument of find or rg is refused when
the line does not set NAME: the environment or a shell startup file an earlier command wrote may hold an option there
(PAT=--pre=tee, F=-exec), and a real shell then writes the file (review r09, r10: bash 5.3.9 and zsh 5.9). The six other
rows (o01, o03, o05, o18, o22, o28) stay allowed. o05 is `find "$PWD" ...`, so one name stays calm: `"$PWD"`, a variable
the shell sets and keeps itself (`hostOwnVar`). The refused row o04 is in `readsBackRefusedRows`, with this reason in its comment.

## Changes

1. `hostPlainVar` compares names without case (ASCII fold): zsh ties cdpath, fignore, psvar and mailpath to the upper-case names.
2. `hostPlainVar` is false for a command that holds `${!` (bash `${!n:=w}`) or `${(` (zsh `${(P)n::=w}`, which zsh 5.9
   runs the same way, and which assigns to PWD even though PWD is set). Rows r07, r08, r22, s01, s02.
3. `hostWholeOf` sets no relaxation for a command that holds `$'..'` or `$".."` (`hostHoldsANSI`: read from the tokens of both
   shell readings, substitution bodies included, so the `$'` that closes `'-x$'` in o22 does not count). Rows r05, r06, r15.
4. An assignment of anything but a number to an integer variable (RANDOM, SRANDOM, UID, BASHPID, HISTCMD, OPTIND, PPID, EUID,
   SECONDS, LINENO and the other integer parameters of bash and zsh, each as `x=`, `x[..]=` or `x+=`) ends the read proof
   in the strict reading too, so the older hole r14 `a=$'x[\x24\x28tee\x20alias\x29]'; RANDOM=a; cat workflows.md` is denied.
   This only tightens: r14 was ALLOW on af68c214, e3eb0da2 and a58becd2. Rows r14, t01-t04.
5. `hostSegmentsOf`: `calm` for a `"$NAME"` needs `hostOwnVar` (the decision above).

## Security notes (not changed here)

- `"$PWD"` stays calm because o05 needs it. A startup file an earlier command wrote (BASH_ENV, ~/.zshenv) can set PWD=-exec, and then
  `find "$PWD" tee alias \;` is a write, the same way r09 is for F. The person decides whether o05 is worth that.
- Arithmetic in an expansion, bash 5.3.9, plain quotes, no `$'`: `a='x[$(tee alias)]'; cat ${x[a]}` and `a='x[$(tee alias)]'; cat ${a:a}`
  are WRITTEN by a real shell and ALLOW on e3eb0da2 and on this lane (kit rows v01, v02). Pre-existing; the same family as r14.
- zsh `${(e)a}` (evaluates a value as an expansion) was not tried. zsh results are `zsh -c` on the laptop only; the VM has no zsh.
