## What changed

- `internal/shot` (new): `ParseBox`, `Load`, `Crop` (box cut, area-average downscale, never upscales, a box outside the picture is an error naming the picture size), `Encode`, `Diff` (per-pixel channel threshold, differing pixels grouped by touching tiles into tight boxes, percentage per box and overall; sizes that differ count the extra area as different).
- `internal/cli/shot.go` and the command table: `grid shot crop` and `grid shot diff`, flags per verb, `--json` for both. Exit 0 whether or not pictures differ; `differs` carries it.
- `internal/cli/inprocess.go`, `contract_inventory_test.go` (route annotations), `contract/commands.json`, `testdata/golden/help.golden`: the places that list every verb, updated for the new one (the walk tests forced these; `make generate` wrote commands.json).
- README, `skills/browser`, `skills/visual-design-review`, `agents/checker.md`.

Not changed: `agent-templates/grid-checker.md` also exists; the brief names only `agents/checker.md`, so it is left alone (open item for the orchestrator).

Decisions: `shot` is a new top-level verb (no existing group fits and it needs no task or project). Diff compares pixels with a channel threshold of 8 so compression noise does not make boxes; `--threshold 0` is exact.
