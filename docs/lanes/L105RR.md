## Changes

- `internal/persongate/proc_linux.go`: when the executable link cannot be read,
  read the process's `comm` and remove its trailing newline. Fall back to
  `args[0]` only if `comm` is also unreadable. Preserve the original arguments.
- `internal/persongate/gate.go`: add `sshd-session` beside `sshd` in the person
  entry list. Environment-marker checks and the entire agent-ancestor walk
  still precede entry recognition; their implementation is unchanged.
- `internal/persongate/proc_linux_test.go`: a fake proc root has no executable
  links and a rewritten `sshd-session: grid@notty` command line. With readable
  `comm`, the chain `grid -> bash -> sshd-session -> sshd -> systemd(1)` allows
  with `via=terminal`. Making both SSH `comm` entries unreadable retains the
  rewritten command lines and refuses with `detached`. Directories at those
  entries make reads fail reliably even under a privileged test runner.
- `internal/persongate/gate_test.go`: cover the full SSH chain, a session with
  no older `sshd` ancestor, an environment marker, and an agent above the SSH
  entry. The latter two remain refused before entry recognition.

Scope is the four person-gate implementation/test files and this lane note;
no changes outside that scope were needed. No module or CLI skeleton changes.
