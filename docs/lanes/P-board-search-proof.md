## What changed

- `internal/brain/query.go`: `Hit.Kind` (empty for a note); `KindNote/KindTask/KindJob/KindPost/KindProposal`, `Kinds`, `ValidKind`; `entryKind` says what a vault entry is from its path (tasks/<T>/board/ is a post, jobs/ a Job, the rest of tasks/<T>/ a task); only result, question, answer and found posts are indexed; `SearchKind(query, topic, kind, limit)` and `Search` calling it. Order is class (note, then history), then score; equal scores keep the project level first. `--kind proposal` searches the notes waiting to be filed.
- `internal/braincmd/command.go`: the `--kind` flag and the usage line. Outside the brief's touches; the flag cannot exist without it.
- `contract/commands.json`: `--kind` on `brain search`. `contract/schemas/cmd-brain-search.json`: optional `kind` on a hit. The schema is outside the touches; the new field needs it.
- `testdata/golden/brain-help.golden`, `brain-search-help.golden`: the help text.
- `agents/library.md` and `agent-templates/grid-library.md` (the template is outside the touches, edited so the two stay the same): the librarian answers from notes first, may narrow with `--kind`, and labels a history hit as history.
- `internal/proof/shot.go`: `AddShot` stores a screenshot of one row at `<task>/proof/<job>-row<N>.png` or `.webp`; a jpg or one-frame gif becomes a png with the same decoded pixels; an animated gif is `ErrAnimated`; `PostBody` returns the record and the relative image link for the post body. The old `proof/<item>/<id>.<ext>` path with proof.json is unchanged.
- `internal/brain/pbsp_search_test.go`, `internal/proof/pbsp_shot_test.go`: the new tests.
