## Decisions
- `--level` takes `home|project` (the command's existing values), not the brief's `project|workspace`.
- `skills` is a reserved topic in `topicAt`, so skills are read straight from `knowledge/skills/<name>/` (folders with SKILL.md); agents go through `ConfigNames`/`safefile.Read`.
- `SKILL.md` front matter keys are checked only in `<skill>/SKILL.md`; `!` lines are checked in SKILL.md and `reference/*.md`.
- Prose is never inspected for proposals: only `topic` decides `config_topic`.
