absolute repository patterns, `../app/*.go`, and `{main}.go`. They receive no
directory grant. The owner expectations in `home_test.go` are restored to
silence. The new table covers an unset role, owner, worker, builder, plugin
aliases, both hook events, an omitted or explicit repository path, and an
unsafe home configuration with no grantable scope.

rooted in the Grid home also retain hard denials for owner and builder,
including traversal, symlink escapes, and mixed brace alternatives. Literal
home roots are recognized before cleaning can erase traversal. Invalid relative
owner patterns decline automatic approval, as the restored owner table requires.

absolute-prefix check. This includes rooted Windows paths without a drive,
UNC patterns, and drive-relative patterns. The Linux table uses literal synthetic
Windows spellings and covers member, lead, guest, and unknown callers for both
hook events; there is no GOOS-based test skip or classification branch.

Members and leads cannot resolve Personal without an identity. The resolver's
default-policy table and CLI tests cover missing identity and plugin role
aliases, for implicit and explicit Personal selection. Owner and machine-session
Personal access remain covered by the existing tests.
