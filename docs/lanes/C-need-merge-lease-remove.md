## What changed

- `grid lease take|release|status task ...` only. Anything else, including bare `take --holder h` and `merge`, prints `Usage: grid lease take|release|status task --task <task> [--project <project>] [--json]` and exits 2; `lease <action> --help` prints it and exits 0. `renew` is no longer an action (a task lease has no renewal); it answers "unknown action", exit 2. The dead `renew` branch in internal/cli/task_lease.go:43-46 is left, as that file is not in Touches.
- contract/commands.json was regenerated with the repo's own generator (a temporary test calling contractCommandWrite, removed again), because `UPDATE_CONTRACT_COMMANDS=1` cannot be set in this shell. The lease entry now lists the task lease's real flags (--epoch, --adopt, --pid, --session, ...) instead of the merge flags.
- Not touched: internal/lease/task.go, job.go (only Record moved in, plus the package comment), activity.go, acquire paths, feed takeover files, --lease/--lease-epoch flags.
