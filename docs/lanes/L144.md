# L144: eight more ported eval cases, and the ported cases' Grid home where the runner points

Base e7908960. Branch lane-L144.

## What changed
- Grid home, all sixteen ported cases: each setup.sh starts with `: "${GRID_HOME:?}"` (so it exits non-zero with a message when unset), builds the Grid home at `$GRID_HOME` (`VERSION`, `projects/<project>/...`) and the project folder at `work/<project>` in the workspace. Each prompt says "My Grid home is the one in GRID_HOME". The runner already sets `GRID_HOME` and `GRID_PROJECTS` for setup (runner.go `taskEnvironment`), so runner.go is unchanged.
- Checks that read Grid-home files are `command_passes` (shell, run with the attempt environment); `file_exists` and `text_contains` are confined to the workspace, so views-skill, memory-skill and questions-skill checks on Grid-home files changed from those types to `test -f` and `grep -F`. Checks on a Grid-home file now start with `test -f` so a missing file exits 1, never 2 (deliver-skill, memory-skill, questions-skill, views-skill had grep or cmp exit 2 on the fresh fixture).
- Eight new tier-b cases (size small) in evals/tasks: execute-check-after-make-together, execute-check-fails, execute-check-fails-out-of-scope, execute-review-changes-rework, execute-review-changes-past-limit, deliver-refuses-closed, preview-skill, agent-reviewer-read-only. Old `ws/projects/<p>/tasks` became `$GRID_HOME/projects/<p>/tasks`; old project files became `work/<p>/...`. The old front matter (max_turns, timeout_seconds, allowed_tools) is dropped. The agent-reviewer-read-only fixture no longer makes a git repo (it needed a committer email); an unchanged-files check replaces it.
- internal/eval/home_test.go (new); suite_test.go `TestSampleSuite`: eight ids appended, nothing loosened.
- No policy key added. The review round limit is the `review rounds:` line of the project's `workflows.md` (in the Grid home, `projects/notes-app/workflows.md`); the plugin requires it in every workflow section (valid values 1, 2, 3, 5), so there is no default. rework writes 3, past-limit writes 2. A test parses both files with `workflow.Parse`.
- No old case was skipped: all eight ported. Not in this lane: the remaining old cases.
