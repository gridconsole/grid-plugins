# L136: check project membership before accepting job task paths

Base: `ecf8a357b05b3a24c6c44b7926d3e7adeee993f8` (`lane-L134`).
Plugin main reference: `2014b233cc839ed379bdde39fd2063751d0effd0`.
Branch: `lane-L136`.

`jobcmd.resolveTask` now treats a local directory containing `plan.md`, or a task
inferred from the working directory, as a selector to resolve. It passes that
selector through the same project-membership resolver as a task ID before
returning a task path. A resolver error is final. Direct package callers without
the CLI callback use `Env.Resolver.Resolve`, so omitting the callback cannot
restore the shortcut.

The L134 matrix no longer has the known-leak skip branch or its obsolete baseline
helper. All recipes, fixtures, byte comparisons, invited assertions and early
answer expectations are unchanged. These five forms now pass in plain and JSON
modes:

| Command | Task path form |
| --- | --- |
| `job lint` | `--task <TASK>` |
| `job render` | `<TASK> I-01` |
| `job show` | `J-01 --task <TASK>` |
| `job show` | `<TASK> J-01` |
| `job verify` | `J-01 --task <TASK>` |

An uninvited guest, missing roles file and unknown project/task produce identical
exit status and streams. Each exits 1. Plain output has empty stdout and stderr
`job: task not found\n`; JSON output has empty stderr and stdout
`{"ok":false,"findings":[],"error":"task not found"}\n`.

New package regressions cover absolute paths, relative paths and local task names
for uninvited guests, missing roles, unknown projects, invited guests, members and
owners. A separate regression checks that a callback refusal remains final for
those selectors and a task inferred from a nested working directory. Existing
tests remain unchanged except for removing the L134 leak exception.

Evidence:

  documented skips.
- Negative control: enabling those rows while restoring only the base

  1058 plain/JSON invocations and 4232 CLI calls, including all invited checks.
- `make test` passes, including the uncached full suite and temp leak check.
- `go test -race -count=1 ./internal/cli/... ./internal/job/jobcmd/...` passes.
- `make lint` passes.
- `make generate` passes; the tracked diff is byte-identical before and after.
- `GOOS=windows go build ./...` and `GOOS=darwin go build ./...` pass.
- `git diff --check` passes.
- The changed files contain no private absolute paths or host identities.

Scope: the brief names `internal/jobcmd/...`, but the existing package lives at
