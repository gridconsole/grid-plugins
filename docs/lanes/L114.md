## Problem and policy

Task workflows could not supply usage notice thresholds. The new
`workflow.UsageNoticeThresholds(taskDir)` reads the top-level
`usage_notice_thresholds` key in task `workflow.md` front matter using the same
delimiter rules and `yaml.Load` as `GatePostRoles`. Missing files or keys return
a nil map. Nested or body keys do not apply. Supplied units must be `tokens`,
`dollars`, or `minutes`, with nonempty lists of positive finite numbers, strictly
increasing and ending at 100. Omitted units remain omitted for the configuration
source to resolve. Invalid units are omitted while valid units survive; errors
name the policy and unit, are joined in sorted unit order, and filesystem read
errors omit the task path.

Integration awaits landed L113, checked by its lane note or commit subjects on
plugin main; its seam has not been recreated here. Expected precedence per unit
is task `thresholds.json`, then `usage_notice_thresholds`, then the default.
