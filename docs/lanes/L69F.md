## Changes

- Rename titles and decline reasons reject all Unicode Cc characters and
  U+202A–U+202E / U+2066–U+2069. Validation inspects the original input, so tabs
  and newlines cannot disappear through whitespace normalization. These errors
  remain `ErrEditUsage`, producing CLI exit 2 before resolution, locking, or
  writing. Rename retains its existing Unicode line/paragraph separator,
  UTF-8, empty-title, and 200-code-point checks. Ordinary Unicode text and
  non-control whitespace remain supported.
- Both replacement and insertion of task header fields use a JSON encoder with
  `SetEscapeHTML(false)`. Quotes and backslashes are escaped; `<`, `>`, and `&`
  remain readable. Existing line-ending preservation is retained.
- Both frontmatter readers decode double-quoted JSON scalars before considering
  inline comments. Escapes, including Unicode escapes and surrogate pairs, are
  decoded, and hashes inside strings remain literal. Decoded strings that look
  like lists or mappings remain strings. The existing fallback dialect and
  inline collection splitting are retained; this is a reader-only change.

```sh
go test -count=1 ./internal/task ./internal/taskfile ./internal/cli -run 'TestRenameDeclineRejectControls|TestRenameTitleRoundTrip|TestQuotedJSONScalars|TestTaskRenameDecline$'
```

Exit 1: all three packages failed, with failures in all four selected test
groups. CLI ESC, BEL, bidi override/isolate, and tab cases returned 0 instead
of 2; decline also accepted a newline. Round-trip failures exposed HTML escapes,
escaped quotes/backslashes, comments inside quoted values, and quoted strings
being reinterpreted as collections. The same command passed after the fix.

Coverage enumerates all 65 Cc characters and all nine requested bidi characters
for both operations. CLI cases assert exit 2, one diagnostic, unchanged file
bytes, and no new files. Rename round trips include `A < B & C`, `issue #12`,
`say "hi"`, `issue # 12`, backslashes, and `修正 café 🚀`, checked through
`task.Read`, `ParseFrontmatter`, and `ScalarFrontmatter`.

## Scope exception

The only change outside the touch list is
`internal/cli/task_rename_decline_test.go`. Two existing success fixtures relied
on tabs/newlines being normalized, which conflicts with rejecting every Cc
character. They now use ordinary spaces and U+2003. The same existing harness
also supplies the minimal CLI regression rows and checks that usage errors
create no files. No CLI production code changed. Existing untracked workspace
files were excluded from commits.
