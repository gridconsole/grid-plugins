## Code fix needed: no
`brain check` resolves the project through the same `where` resolver as the other brain verbs before it reads anything. An uninvited, no-roles or unknown guest gets the same answer for a project they are not in and for an unknown project, with no host path or brain content:
- plain: exit 1, stderr `brain: project "alpha" is not registered`, empty stdout
- `--json`: exit 1, stderr `{"error":"project \"alpha\" is not registered"}`, empty stdout
- the invited guest gets exit 0 (`checked: 0` / `{"checked":0,"findings":[]}`), so the invited-differs check is not vacuous.

`brain check` takes `--project` and `--level`, not `--task` (see `contract/commands.json`), so the parity rows are the project forms.
