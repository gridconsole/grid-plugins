## Task verb audit

Searched the CLI's task help, dispatch and handlers with:

```sh
rg -n 'grid task |case "task"|func runTask' internal/cli --glob '*.go' --glob '!**/*_test.go'
```

Traced `runTask`, `runTaskWrite`, `runTaskAttach` and `runTaskIntent` into their
stores. After this change, the remaining task writers outside `gateVerb` are:

| Verb | Write behavior | Existing boundary |
| --- | --- | --- |
| `task new` | Creates a task and its initial records via `task.Store.New`. | Explicitly allowed by `TestHostAllowsOtherGridVerbsAndLookalikes`. |
| `task attach` | Starts a session record and commits an attach event/history via `task.Store.Attach`. | The CLI passes agent identity and the bound task; the store restricts agents to their assigned task. |
| `task move` | Enqueues a move request via `intent.Store.Enqueue`. | CLI checks project transport prerequisites; `gateVerb` does not block the command. |

These three writers remain unchanged: this lane adds the four requested gates
and reports the other writers for policy review. `task show`, `task list` and
`task history` are read commands. Task lease writes use `grid lease`, not the
`grid task` command family. No other dispatched `grid task` writer was found.
