## Changes

- Rename titles and decline reasons reject Unicode noncharacters through the
  standard library's `unicode.Noncharacter_Code_Point` table. Validation returns
  `ErrEditUsage` before task resolution, locking, or YAML encoding, giving CLI
  exit 2. Existing control and bidi override/isolate checks remain in place;
  diagnostics now name noncharacters too.
- The frontmatter reader test pins `title: "a" b` to the literal string
  `"a" b` through both readers. No reader implementation change was necessary.
- Workflow show maps project discovery's `localdata.ErrUnsafePath` to exit 2
  with the fixed diagnostic `workflow path is unsafe or inaccessible`, without
  printing the underlying path. Coverage checks all-project discovery and
  selection by project name or ID, in both plain and JSON modes.
- The contract documents invalid title/reason code points, workflow write's
  linked or non-regular target exit 2, and show's linked-project refusal.

## Regression evidence

Because main lacked the prerequisite APIs, the red/green check used main plus
the two requested merges, before any L74 production changes:

```sh
go test -count=1 ./internal/task ./internal/taskfile ./internal/cli -run 'TestRenameDeclineRejectNoncharacters|TestQuotedJSONScalars|TestTaskRenameDecline$|TestWorkflowShowLinkedProject'
```

The command failed on that baseline and passed after the fix:

- All 66 noncharacters failed early-validation assertions for both task edits:
  U+FDD0–U+FDEF and the last two code points of each of the 17 Unicode planes.
- CLI rename returned exit 1 with a go-yaml diagnostic for U+FFFE/U+FFFF;
  U+FDD0, U+1FFFE, and U+10FFFF were accepted. Decline accepted all five tested
  values. All ten rows now return exit 2 and use the existing snapshot checks
  to verify unchanged task bytes and no new files.
- All six linked-project show cases returned exit 1 with an absolute path.
  They now assert exit 2, empty stdout, and the exact fixed diagnostic.

The frontmatter row intentionally passes on the baseline because it preserves
existing fallback behavior. Temporarily replacing quoted-scalar suffix
validation with unconditional success made the new row fail through both
readers, catching the M5 behavior. The mutation was restored before validation;
`internal/taskfile/frontmatter.go` has no lane diff.
