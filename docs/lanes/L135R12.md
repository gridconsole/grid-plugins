## Change

`hostOpaqueOption` (find and rg, the commands the rule covers) now counts an unquoted word that starts with `~` and a `+`, `-`
or a digit as a runner, never a read, calm or not. Such a word expands to the zsh directory stack (`~N`, `~+N`, `~-N`), PWD
(`~+`) or OLDPWD (`~-`), which the line may have set to an option (`dirstack[1]=-exec`, `OLDPWD=-exec`), and find or rg then reads
the result as one. The word has no `$`, so it is calm in the relaxed reading; the new clause therefore comes before the calm test.

The tokenizer records whether a word began with a `~` that is neither quoted nor escaped (`hostShellToken.tilde`, set in the
unquoted default branch only while the word has not started). `'~-'`, `"~1"` and `\~-` are plain text and keep their verdict, as do
`~`, `~/x` and `~user`.
