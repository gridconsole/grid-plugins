## Existing rows tightened (read first)

Two existing assertions now expect deny; no other existing row changed.

1. `read_then_write` (`internal/guard/host_write_targets_test.go`),
   `cat alias; echo x > notes.md`. The decision names this line as the accepted
   cost, so the row cannot stay green.
2. `case_subst_read` (`internal/guard/host_write_targets_case_test.go:43`),
   `echo $(case x in x) cat alias;; esac)`. `case` is not a read-only command, so
   the tokenizer does not prove the line read-only and the floor resolves `alias`.
   Main refused it too. Flipped by the orchestrator's decision (guard-word-floor):
   the floor does not trust `case`/`esac`, so it is not added to the read-only proof.

## What changed

1. **Floor** (`host.go` `floorReason`, called in `EvaluateHost` after
   `protectedWriteReason`). Main's literal-word check is back: every word of the
   whole command (`shellPathWord`, then `words`), heredoc bodies, comments and text
   after `<<` included, is resolved and refused when it is a protected file
   (settings, gate or workflow, through `writeScan.protected`). It is skipped only
   when `hostProvenReads` holds: every segment read-only in both shell readings, in
   every substitution, no refuse, no `$[` or `((` in the text and no heredoc with an
   unquoted delimiter. Main's textual `onlyReads` is not the gate: it would turn
   eleven existing allow rows red (`group_hash_*`, `comment_text`,
   `doc_quoted_substitution`, `read_alias_redirect`, `cd_expansion_read`).
2. **`#` after a bracket.** A `#` that would start a comment right after `(`, `)`,
   `<` or `>` refuses the command (`hostHashRefused`): in the tokenizer, in
   `hostJoinLines`, and in `hostShellGroupAs`, where such a `#` no longer opens a
   comment, so the group end is found and the body's tokenizer refuses.
   `hostHasComment` already counts these bytes and refuses. A `#` after the `)` of
   `$(..)` or `<(..)` stays a word byte, as the shells read it.
3. **`find -fprint0`** added to `findWrites` (`-fprint`, `-fprintf`, `-fls` were
   there; rows added for all four).
4. **`rg --pre`/`--pre=`** makes rg a non-read command in `readCommand` and
   `onlyReads` (`readerRuns`); `--pre-glob` alone stays a read.
