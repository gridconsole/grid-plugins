## Changes

- One shared check validates original input before normalization, resolution,
  locks, allocation, journals, or task writes. It rejects invalid UTF-8,
  controls, U+2028/U+2029, U+202A–U+202E, U+2066–U+2069, U+FDD0–U+FDEF,
  and the last two code points of every Unicode plane (66 noncharacters).
  `encodeTaskScalar` also checks its input before encoding.
- Rename titles and decline reasons use the same check. Creation words,
  workflow and author fields, state-change reasons, history notes, approval
  and refusal notes, delivery outcomes and authors, and attachment receipt
  text use it too. Forbidden text returns `ErrEditUsage`, mapped to exit 2.
- Freeform words, outcomes, and receipt notes permit tab and newline. Rename,
  decline, names, and identifiers permit neither. History retains tab support
  but refuses newline with exit 2; its existing empty-note behavior remains.
- List keeps readable tasks and emits exactly one stderr warning per unreadable
  folder, quoting its folder name so embedded line breaks cannot split the
  diagnostic. Read failures and project mismatches become placeholders.
  Plain output contains only readable tasks; show still fails on a bad task.
- JSON uses optional boolean **`unreadable`**: `true` marks a placeholder with
  folder-derived `id`, resolved `project`, and `path`. Other required string
  fields are empty; readable entries omit the marker. Placeholders remain in
  numeric order and survive state filters because their state is unknown.
  The list JSON schema documents the field. Project resolution, enumeration,
  invalid numeric folder names, and duplicate IDs still fail normally.

## Scope

No explicit touch list was supplied beyond the named task and CLI work.
The minimal supporting changes are the list schema, the existing list test
that formerly required a project-wide failure, and the history CLI expectation
for newline refusals. Task creation, state/history writes, gates, delivery,
and attachment needed the shared validation to meet the requirement for every
task text field. CLI history, delivery, and write-result handlers map these
usage errors to exit 2. The module and Makefile were retained; existing
untracked workspace files were excluded from commits.
