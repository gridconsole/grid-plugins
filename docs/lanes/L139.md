## Grader mapping
Rules: regex on a file -> `command_passes` with `grep -Eq` (the `m` flag is grep's own per-line mode; `\d` -> `[0-9]`, `(?:` -> `(`; a pattern across lines -> `tr '\n' '~' < file | grep ...`; `match: not_contains` -> `! grep`); a pure literal -> `text_contains` or `grep -F`/`cmp`; file_exists -> `file_exists`; llm -> `llm_judge` with its rubric (its `focus: trace` is dropped, the judge sees the workspace).
