## Changes

- Unix source opens use `O_RDONLY|O_NONBLOCK`, then Fstat rejects non-regular
  files. No `O_NOFOLLOW`: symlinked plans still reach identity checks. Identity,
  content reads, and approval checks continue to use the same opened snapshot.
  The non-Unix helper retains ordinary opening. A Unix regression covers repo,
  prototype, and task FIFO pointers with a one-second deadline; on failure it
  opens a nonblocking writer to release the old reader and avoid a leaked test.
- Digest again hashes canonical content, processing line one as well. It keeps
  tick, trailing-whitespace, CRLF, boundary-blank-line, and Where-it-stands
  normalization. Evidence and needs remain covered. The short Hash is unchanged.
- Canonicalization retains source line numbers. Plan line ranges (`#L...` and
  `:a-b`) refuse any omitted line, returning no selected text. Generic heading
  anchors use the same check so the status section cannot bypass it. Covered
  ranges, step and verify anchors, and hardlink/symlink identity behavior remain
  supported. This also refuses trimmed boundary blank lines.
- Restored the ticking assertion in `TestApprovalTracksPlan`. Added status,
  whitespace, CRLF, first-line, old-receipt, and real LoadPlan/anchor regressions.
  Existing first-line and alias regressions remain green.

## Which approvals survive

A receipt is accepted only when its stored short hash and full digest equal the
current values, with the existing task/gate checks still satisfied. No fallback
or silent receipt migration was added.

Pre-L107 canonical receipts omitted line one. They survive only if processing
line one leaves the canonical digest input unchanged from that old view (and
nothing else covered has changed). A blank first line is a tested surviving
case. Normal revision headings and first-line steps add content, so those old
receipts become invalid **even when line one itself has not been edited**.
Merely saying “line one is unchanged” would overstate compatibility.

L107 receipts hashed raw bytes. They survive only when the stored raw digest
matches the new canonical digest. The tests cover an already-canonical titled
plan that survives, and a ticked raw plan that requires reapproval. Receipts
with no full digest remain invalid. Existing malformed/wrong-digest tests pass.

After approval with this version, bare ticks and Where-it-stands prose rewrites
keep approval, including LoadPlan and reused anchor resolvers. CRLF and trailing
spaces keep it too. Substantive first-line edits cancel approval. Evidence or
needs edits still cancel approval, including when added with a tick.

For a stale receipt, review the plan, obtain the current short hash with
`grid plan hash --task T-NN`, and run
`grid approve T-NN --plan-hash <current-hash>` while the task is waiting at the
plan gate. The compatibility tests verify refusal of implicit migration and
successful explicit reapproval.
